# Dataset Details

## Dataset Name

Cloud Carbon Footprint and Cloud Resource Utilization Dataset

## Sources

- Electricity Maps
- Cloud Carbon Footprint Project
- AWS CloudWatch Sample Metrics
- Kaggle Cloud Resource Utilization Dataset

## Dataset Characteristics

- Size: Approximately 50–100 MB
- Records: Around 100,000
- Features: 15–20
- Data Type: Numerical, Categorical and Time-Series

## Important Features

- Resource ID
- CPU Utilization
- Memory Usage
- Storage Usage
- Network Traffic
- Runtime
- Power Consumption
- Carbon Intensity
- Estimated Carbon Emission
- Sustainability Score
- Timestamp
- Cloud Region

## Purpose

The dataset is used for:

- Carbon emission estimation
- AI model training
- Digital Carbon Passport generation
- Sustainability analytics
- Resource optimization

## Preprocessing

- Missing value handling
- Duplicate removal
- Feature scaling
- Normalization
- Outlier removal
- Timestamp processing
- Train-test split
