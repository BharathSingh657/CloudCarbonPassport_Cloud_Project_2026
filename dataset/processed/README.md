# Processed Datasets

`carbon_timeseries_dataset.csv` contains 8,640 records of hourly cloud workload telemetry across 8 simulated multi-cloud instances over 45 days. It includes CPU, memory, storage, network traffic, server power draw (W), energy consumed (kWh), regional carbon intensity (g/kWh), Scope 2 and Scope 3 emissions, and sustainability score.
